# depcurfew.github.io

The documentation site of [depcurfew](https://github.com/DevXord/depcurfew), published at https://depcurfew.github.io.

Every file here is generated by `npm run site -- --versions` in the depcurfew repository, from its README, knowledge base, `schema.json` and release tags. Do not edit them by hand: change the depcurfew repository instead.

The root documents the current version; `/<version>/` (for example `/1.3.0/`) keeps the documentation of each earlier release, and `versions.html` lists them.
